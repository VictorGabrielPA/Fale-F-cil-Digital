Sistema de Reclamações criado para resolver a demanda de uma empresa. A empresa pediu uma solução que resolvesse o problema de gargalo ao utilizar formulários físicos para reclamações de funcionários (Fale Fácil).
Ao automatizar o sistema criando a ferramenta Fale Fácil Digital, resolvi o problema apresentando uma solução automática, prática e viável, através de um site.
Foram utilizadas as tecnologias HTML, CSS e JavaScript.
